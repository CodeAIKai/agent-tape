# AgentTape 项目申报书

**1. 项目名称**

AgentTape：MoonBit 原生工具调用回放与失败片段缩减工具。

**2. 项目简介**

工具调用失败后，直接重跑容易受到外部服务变化影响，还可能重复发送消息或执行其他副作用。AgentTape 将调用事件、授权记录、检查策略与预置响应组织成 JSON 磁带，用 MoonBit 内核进行确定性检查和离线回放，再将失败轨迹缩减为便于复现与交流的片段。开发者无需再次执行真实工具，即可查看违规位置及对应证据。

**3. 项目方向与通用性**

方向为 MoonBit 开发工具与测试基础组件。项目面向工具调用应用的开发者、测试人员和开源维护者，不绑定特定模型、服务商或业务行业。Node 命令行与浏览器共用同一编译内核；其他系统可将脱敏轨迹转换为磁带协议后接入，目前不提供通用框架适配器。

**4. 预期使用场景**

- **排查未授权操作：** 开发者输入包含发送操作的调用磁带，运行回放，检查授权是否先于调用且与调用标识、工具及参数一致；获得具体违规步骤，用于修正授权流程，过程中不实际发送消息。
- **验证回归与结果漂移：** 测试人员保留一份预置响应，对修改后的调用记录运行检查；得到结果差异、预算或调用次数违规及命令行退出码，供本地回归测试或持续集成使用。
- **分享可复现的问题：** 开源贡献者将失败磁带缩减为保留目标违规代码的事件子序列，导出报告并附上原始上下文；维护者在本地离线复验，减少阅读无关调用记录的工作量。

**5. 核心功能与交付范围**

已实现磁带格式与边界校验、工具白名单、累计记录成本和调用次数检查、事前授权绑定、预置响应精确匹配、结果漂移检测、失败缩减与报告导出。随仓库交付 MoonBit 源码、JS 编译产物、命令行和浏览器演示、三类示例、自动化测试及使用文档。核心与宿主测试已通过；缺少授权示例可由 3 个事件缩减为 1 个。

本项目检查历史轨迹，不验证授权签名或强制线上权限；缩减最多接受 60 个事件，保证无法继续单条删除而保留目标违规代码，不保证全局最短或相同根因。演示使用合成数据。

**6. 原创与参考关系**

本项目为原创实现，非现有项目的代码移植。设计参考已有的录制回放、轨迹评估与策略授权方法，主要实现工作是将规则检查、预置响应回放及失败缩减组合为共享的 MoonBit 内核。
