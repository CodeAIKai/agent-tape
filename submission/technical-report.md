# AgentTape 技术与验收说明

2026 MoonBit 9 月黑客松

版本：0.1.0。主要实现语言：MoonBit。

项目仓库：https://github.com/CodeAIKai/agent-tape

### 目标与使用者

面向需要复现工具调用失败的开发者，提供本地 JSON 轨迹检查、fixture 回放和失败片段缩减。典型用途是将一次失败保存成脱敏回归用例，供开发者在没有外部服务的情况下复验。

### 内核与数据协议

MoonBit 定义事件、策略、fixture 和报告类型，通过官方 JSON 解码后校验数据边界。磁带版本为 1，事件和 fixture 各最多 300 条，输入文本最多 200,000 字符；缩减最多接受 60 个事件。成本使用非负整数，参数键按精确字符串匹配。

### 确定性检查与回放

内核按事件顺序检查工具白名单、累计记录成本、调用次数和事前授权。授权必须先于目标调用，并同时匹配调用 ID、工具名称与参数键。工具响应从 fixture 中读取，与磁带记录结果比较；缺失时报告 MISSING_FIXTURE，结果不一致时报告 RESULT_DRIFT。内核不访问网络或执行真实工具。

### 失败片段缩减

缩减器默认以原始报告的首个违规代码为目标，也可指定违规代码和调用标识，反复尝试删除单条事件并复验，直到无法继续删除。输出包含缩减前后事件数、目标违规与调用标识、删除的事件标识、缩减磁带及其检查报告。结果是针对该违规代码的 1-minimal 子序列，不保证全局最短，也不保证保留相同根因。

### 命令行与浏览器

可导入的 MoonBit 核心包位于 src/core，提供 evaluate_json、minimize_json 和 minimize_target_json；JS 绑定位于 src/main.mbt。Node CLI 读取磁带文件、调用内核并输出 JSON；浏览器使用同一产物，实现本地文件导入、示例切换、回放、指定目标缩减和报告下载。JavaScript 仅负责输入输出与展示，不重复实现策略规则。

### 验收结果

16 项核心测试覆盖授权绑定、迟到授权、预算边界、缺失 fixture、结果漂移、工具限制、负成本、重复 ID、schema 错误及确定性。宿主集成测试进一步验证编译导出、12 组预算边界、输入上限和缩减后的单条删除最小性。另有 64 组固定种子生成磁带和 832 次性质断言、批量回归清单验证、浏览器交互与 JSON Schema 契约检查。测试输出保存在 evidence/test_results.txt。

缺少授权的合成磁带从 3 个事件缩减到 1 个，保留 APPROVAL_REQUIRED；授权完整示例通过检查，结果漂移示例报告对应错误。浏览器在桌面和移动视口完成交互检查，无控制台错误或横向溢出。

### 复现与交付

仓库附带编译产物，Node.js 20 或更新版本即可运行 npm test 和命令行演示，无需安装 npm 依赖。构建源码需要 MoonBit 工具链，执行 bash scripts/build.sh 可运行核心测试、重新编译并验证宿主集成。实测工具链记录在 evidence/toolchain.txt。

submission/ 提供一页项目说明、本文、路演演示文稿和 112 秒实际操作视频。视频包含中文旁白与字幕，演示缺少授权、失败缩减、授权完整和结果漂移四个流程。

### 适用边界与来源

该工具检查历史轨迹，不执行完整智能体、不验证授权签名、不提供线上安全隔离、不自动脱敏，也不支持通用外部轨迹导入。示例均为合成数据，当前没有外部项目采用的验证记录。可选报告解读独立于内核，不改变判定结果。

设计参考 VCR.py 的录制回放、LangSmith 的轨迹评估和 Cedar 的策略授权问题，未复制其实现。原创代码采用 Apache-2.0；开发与材料来源见 PROVENANCE.md，第三方依赖与许可见 THIRD_PARTY.md 和 third_party/。
