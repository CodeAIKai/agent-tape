# AgentTape
## MoonBit 原生工具调用回放与失败片段缩减

2026 MoonBit 9 月黑客松 · 版本 0.1.0

项目仓库：https://github.com/CodeAIKai/agent-tape

**问题。** 工具调用失败往往难以复现：重新执行会受外部服务状态影响，也可能产生重复副作用。开发者需要可以保存、分享和复验的失败样本。

**方案。** 用版本化 JSON 磁带描述事件、策略和预置响应。MoonBit 内核检查工具白名单、调用次数、记录成本和事前授权，按参数精确匹配响应并发现结果漂移。缺少响应时直接报告失败，全程不执行真实工具。

**核心价值。** 在同一个可嵌入内核中组合离线回放、轨迹规则与失败缩减；Node CLI 和浏览器共享编译产物。缩减反复删除事件并复验，得到保留目标违规代码、无法再单条删除的片段。

**可验证结果。** 缺少授权的示例从 3 个事件缩减为 1 个，保留 APPROVAL_REQUIRED；另提供授权完整和结果漂移示例。16 项 MoonBit 核心测试及宿主集成测试通过，结果保存在 evidence/。

**交付。** MoonBit 源码、JS 编译产物、命令行工具、浏览器演示、示例、测试、技术说明、路演文件与 112 秒配音视频。所有核心功能可直接本地运行，无需密钥。

**复现。** 克隆仓库后运行 npm test；执行 node scripts/replay.mjs fixtures/missing-approval.json --minimize。运行 python3 -m http.server 8013 --bind 127.0.0.1 --directory web 后访问本地 8013 端口，可操作视频中的完整流程。

**边界。** 检查历史轨迹，不验证授权签名或强制线上权限。缩减不保证全局最短或相同根因。示例均为合成数据。原创实现采用 Apache-2.0，来源和许可证随仓库提供。
